# LinkedIn Auto-Post

Generates a LinkedIn post every Tuesday using your weekly notes + Groq AI, emails it to you, and archives it to the repo.

## How it works

1. Every Tuesday at 07:00 UTC, GitHub Actions runs `generate_post.py`
2. The script reads your `notes.md` bullets + the style guide in `prompt_template.txt`
3. It loads the last 3 archived posts to avoid repeating themes
4. Groq (`llama-3.3-70b-versatile`) generates a 150-250 word post
5. The post is emailed to you as styled HTML
6. The post is archived to `past_posts/YYYY-MM-DD.txt` and committed back

## Setup

### 1. Fork or clone this repo to your GitHub account

### 2. Add GitHub Secrets

Go to **Settings → Secrets and variables → Actions → New repository secret** and add:

| Secret | Where to get it |
|---|---|
| `GROQ_API_KEY` | [console.groq.com](https://console.groq.com) → API Keys |
| `GMAIL_USER` | Your full Gmail address (e.g. `you@gmail.com`) |
| `GMAIL_APP_PASSWORD` | Google Account → Security → 2-Step Verification → App passwords → generate one for "Mail" |
| `TO_EMAIL` | Where to send the draft (can be same as `GMAIL_USER`) |

> **Note:** `GMAIL_APP_PASSWORD` is a 16-character password generated by Google — NOT your regular Gmail password. Requires 2FA to be enabled on your Google account.

### 3. Edit `notes.md` each week

Replace the placeholder bullets with what you actually did that week. Be specific — texture beats vague summaries.

```markdown
# Weekly Notes

- Spent 3 hours debugging a timezone bug — turned out UTC vs local time mismatch in cron job
- Read "A Philosophy of Software Design" ch. 4 — deep modules vs shallow modules concept clicked
- Finally shipped the auto-post workflow, first real GitHub Actions project
```

### 4. Let it run

The workflow fires automatically every Tuesday at 07:00 UTC. Check your inbox for the draft, edit if needed, then post to LinkedIn manually.

### Manual test run

Trigger the workflow manually from **Actions → Generate LinkedIn Post → Run workflow** to test without waiting for Tuesday.

## Weekly usage

1. **Monday or Tuesday morning:** Edit `notes.md` with your week's bullets
2. **Tuesday ~07:00 UTC:** Email arrives with draft post
3. **Review and edit** the draft (it's a starting point, not a final product)
4. **Post to LinkedIn** manually

## Repo structure

```
├── .github/workflows/post.yml   # Cron + manual trigger
├── generate_post.py              # All logic
├── prompt_template.txt           # Style guide for Groq
├── notes.md                      # Your weekly bullets (edit this)
├── past_posts/                   # Auto-archived posts
└── README.md
```

## Customising the style

Edit `prompt_template.txt` to change the post style. The file is a system prompt — rewrite any part of it. Changes take effect on the next run.
